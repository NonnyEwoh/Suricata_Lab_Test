# Project Information

**Project:** Suricata IDS Practical Lab  
**Purpose:** Beginner-friendly, authorized network intrusion detection exercise.  
**Primary platform:** Kali Linux / Debian / Ubuntu  
**Detection:** Custom Suricata rule + Netcat controlled TCP traffic  
**Portfolio evidence:** interface identification, configuration validation, alert generation, fast.log and EVE JSON analysis.

Replace `<SURICATA_IP>`, `<CLIENT_IP>`, and `<INTERFACE>` with your own lab values before execution.
